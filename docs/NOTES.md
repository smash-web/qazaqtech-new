# Заметки и план

## Сейчас (тестовый этап)
- **ИИ не подключён.** Конвейер собирает новости, группирует их в сюжеты, оценивает важность по эвристике (охват источников, авторитетность, свежесть) и рубрицирует по ключевым словам. Отобранные сюжеты попадают в админку черновиками «На модерации» с отметкой «Нужен перевод». В черновике есть анонсы источников на языке оригинала и ссылки. На сайт автоматически ничего не публикуется.
- Инфраструктура: GitHub (код и Actions для конвейера), Vercel (сайт и админка), Supabase (PostgreSQL, схемы `cms` и `pipeline`).

## Подключить позже: ИИ
1. Получить ключ на https://console.anthropic.com.
2. Добавить секрет `ANTHROPIC_API_KEY` в GitHub → Settings → Secrets → Actions.

Больше ничего менять не нужно. Конвейер сам переключится:
- **оценка и отбор:** модель `SCORER_MODEL` (по умолчанию claude-haiku-5-5) оценивает сюжеты по редакционной политике из админки;
- **перевод и написание:** `WRITER_MODEL` (claude-sonnet-5-5) пишет оригинальный текст на казахском по глоссарию и стилевому гайду;
- **проверка:** второй проход сверяет факты с источниками.

После этого можно включить «Публиковать автоматически» в «Настройках конвейера».

Альтернативные провайдеры (другие LLM, переводчики) подключаются через интерфейс `LLM` в `pipeline/qtnews/llm.py`: достаточно реализовать метод `complete()`.

## Состояние тестового стенда
- Сайт и админка: https://qazaqtech-web.vercel.app (`/admin`). Проект Vercel `qazaqtech-web`, корень `web/`.
- Конвейер: проект Vercel `qazaqtech-pipeline`, корень `pipeline/`, функция `/api/run`. Запуск по расписанию через pg_cron + pg_net в Supabase (каждые 30 мин).
- База: Supabase `qazaqtech-news` (eu-central-1), роль `qtnews`, схемы `cms` (Payload) и `pipeline`. Сайт ходит через transaction pooler (6543), конвейер через session pooler (5432).
- Схема CMS и стартовые данные созданы командой `npm run seed` при `NODE_ENV=development`.
- **Обновление схемы БД после изменения коллекций или плагинов:** `cd web && NODE_ENV=development BLOB_READ_WRITE_TOKEN=<любой> DATABASE_URI=<session pooler 5432> PAYLOAD_DB_SCHEMA=cms npx tsx src/seed.ts`. Токен Blob нужен, иначе плагин хранилища отключён и его поля (`_objectKey`) не попадут в схему. Перед боевым запуском перейти на миграции.
- Медиа: Vercel Blob `qazaqtech-media` (fra1). Фото к тестовым статьям взяты с Wikimedia Commons (CC BY-SA 4.0 / общественное достояние), автор и лицензия указаны в поле «Автор / лицензия».
- Версии: Payload 3.93 требует Next.js 15.4.11+ (или 16.3.3+), поэтому `next` закреплён на `~15.4.11`.
- VentureBeat отвечает 429 на запросы бота. Business Insider переключён на ленту feedburner (весь BI, не только tech).

## Прочее, отложенное
- **Медиа на Vercel.** Файловая система на Vercel только для чтения, поэтому загрузка картинок в админке не сохранится. Решение: `@payloadcms/storage-vercel-blob` или S3 (Supabase Storage / Cloudflare R2).
- **Миграции.** Сейчас схему CMS синхронизирует workflow `bootstrap` (dev-push). Перед боевым запуском перейти на `payload migrate:create` / `payload migrate`.
- **Источники без RSS** (Reuters, Semafor, Axios Pro). Нужен лицензионный доступ или новостной API.
- **Nikkei Asia** выключен: его лента не только про технологии. Включить, когда отбор будет делать ИИ.
- Telegram-канал, push-уведомления, Google News sitemap, латиница.


## Известные слабые места конвейера без ИИ (исправит ИИ-оценка)
- Кластеризация TF-IDF не склеивает публикации об одном событии с разными заголовками (скандал Nvidia разошёлся на ~15 сюжетов) и иногда склеивает лишнее (общий спикер в видео Bloomberg). С эмбеддингами или ИИ-оценкой это уйдёт.
- Эвристика завышает Bloomberg/The Information из-за веса источника, в том числе видео и подкасты.
- Промокоды и распродажи теперь отсекаются фильтром `JUNK_TITLE` в `scoring.py`.


## Бесплатный режим ИИ для демо: Google Gemini
- Если в окружении конвейера нет `ANTHROPIC_API_KEY`, но есть `GEMINI_API_KEY`, конвейер пишет статьи через Gemini (бесплатный тариф Google AI Studio).
- Модели по умолчанию (через запятую — запасные на случай перегрузки 503): написание `gemini-3.5-flash,gemini-3.6-flash,gemini-3.5-flash-lite`, проверка и отбор `gemini-3.5-flash-lite,gemini-3.1-flash-lite`. Флагманы 3.8/3.6 Flash на бесплатном тарифе часто перегружены (переменные `GEMINI_WRITER_MODEL`, `GEMINI_QA_MODEL`, `GEMINI_SCORER_MODEL`).
- Бесплатные лимиты малы (у Flash порядка десятков запросов в день), поэтому для демо: `MAX_ARTICLES_PER_RUN=2`, «Статей в день» ≈ 12. Между вызовами пауза 7 с.
- На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов — для публичных новостей это допустимо, для приватных данных нет.
- Для боевого режима: добавить `ANTHROPIC_API_KEY` — конвейер сам переключится на Claude.

## Фото обязательно (с 10.11.2026)
- Писатель (ИИ) возвращает `image_queries` (англ.) и `image_alt`; `qtnews/images.py` ищет на Wikimedia Commons
  фото со свободной лицензией (CC BY / BY-SA / CC0 / PD), без людей (категории/«personality rights»),
  горизонтальное ≥900px; затем запасные запросы по рубрике. Фото загружается в медиатеку с подписью.
- Нет фото → статья НЕ публикуется: статус review + пометка в qaNotes. Каждый запуск `backfill_covers`
  повторяет поиск (до 4 статей), ставит обложку и выпускает отложенные. Отключить: `REQUIRE_IMAGE=false`.
- Ручной запуск: `POST /api/run?step=covers` или `python -m qtnews.main covers`.

## Дубли сюжетов
- Перед написанием статьи сюжет сверяется с уже вышедшими за окно: явное сходство заголовков (≥ DUPLICATE_THRESHOLD)
  — дубль сразу; сомнительные кандидаты решает ИИ (scorer-модель). Дубль → статус skipped.

## Лимит 5 минут (Vercel Hobby)
- Сбор и обработка — отдельные задачи pg_cron: `qtnews-collect` (:00/:30, `?step=collect`) и
  `qtnews-pipeline` (:03/:33, `?step=process`), у каждой свои 300 с.
- В обработке действует бюджет времени (RUN_BUDGET_SECONDS=285): новую статью начинаем, только если осталось
  ≥ ARTICLE_SECONDS (150 с), обложку — ≥ COVER_SECONDS (60 с). Запросы к ИИ не начинаются и не повторяются у края
  лимита (DeadlineExceeded); недописанный сюжет остаётся SELECTED без штрафа и уходит в следующий запуск.
